# JRSE submission metadata checklist

Official requirements checked on **2026-08-27** against the [JRSE scope page](https://pubs.aip.org/aip/jrse/pages/about), [JRSE charges page](https://pubs.aip.org/aip/jrse/pages/charges), and [AIP author instructions](https://publishing.aip.org/resources/researchers/author-instructions/).

## Journal and article

- [ ] Confirm target: *Journal of Renewable and Sustainable Energy*.
- [ ] Select **Research Article** in the submission system.
- [ ] Confirm final title.
- [ ] Confirm abstract (single paragraph, no citations/equations/tables/figures, no more than 250 words).
- [ ] Confirm keywords; the official instructions reviewed do not state a numeric JRSE keyword limit.
- [ ] Confirm subscription/traditional route; do **not** select optional Author Select unless the authors explicitly authorize the USD 3,800 APC.
- [ ] Reconfirm any conditional production fee with JRSE. The official charges page states no page charges; online color is free under AIP’s graphics policy.
- [ ] `INDEXING_STATUS_REQUIRES_AUTHOR_OR_LIBRARY_CONFIRMATION` through Clarivate Master Journal List/JCR.

## Authors and declarations — human completion required

- [ ] Final author names and order.
- [ ] Corresponding author(s).
- [ ] Affiliations and full postal addresses.
- [ ] Email addresses.
- [ ] ORCID identifiers and account links.
- [ ] CRediT contribution statement agreed by every author (AIP requires it).
- [ ] Funding agency names and grant numbers, or confirmed no-funding wording.
- [ ] Conflict of Interest statement (AIP requires a statement even when none exist).
- [ ] Data Availability statement and whether derived evidence will be deposited (JRSE offers a Zenodo data-accessibility route).
- [ ] Code Availability wording and repository release state.
- [ ] Ethics applicability; this public observational-data study appears not to involve humans or animals, but the authors must confirm the submission-system answer.
- [ ] Exclusive-submission / not-under-consideration statement.
- [ ] Explicit approval by all authors.
- [ ] Related manuscript, preprint, or conference-paper disclosure.
- [ ] Suggested reviewers and reasons.
- [ ] Opposed reviewers and reasons.
- [ ] Open-access choice and fee payer/funding source if OA is selected.

## Files and accessibility

- [ ] Upload the compiled manuscript PDF for initial submission.
- [ ] Confirm every figure and table is cited, numbered, captioned, and legible.
- [ ] Prepare 25–50-word alt text for every figure and table for revision; AIP requests a separate TXT or DOCX then.
- [ ] If supplementary material is added later, upload one separate supplementary PDF and add the required manuscript section. None is included now.
- [ ] At source-file request/acceptance, upload `main.tex`, `references.bib`, and the four figure PDFs using the AIP LaTeX template structure.
- [ ] Confirm PDF fonts are embedded and the generated PDF is the version approved by all authors.
- [ ] AIP recommends a highlight image for revised submissions; if none is supplied, Figure 1 may be used. This is not treated as an initial-submission requirement.
